# hekouwang 主题验收样张

这一份文档把 Typora 会渲染的元素基本铺满了，用来逐项验收排版。中英混排是重点：西文走 Anthropic Sans / Inter，中文自动 fallback 到苹方——**这不是妥协，桌面端本身就是这个机制**。

## 阅读体验验收（三类场景）

打开本文件与真实工作文档，各盯 3 分钟：

1. **散文段落**：段与段像在读文章，不是在扫色块
2. **长 checklist**（见下方任务列表）：勾选清晰，但页面仍是「字」不是「卡片墙」
3. **代码 + 表格 + `> ![]` 截图**：灰底只出现在该出现的块上，截图外无画框

默认对齐 **Claude 桌面端真实参数**（采样自 Claude.app）：
Anthropic Sans（西文）+ 系统中文、正文 **14px / leading 1.42857**、行宽 **65ch**、
列表 disc 20px、标题阶接近 file-prose、代码块浅沉底。本机装有 Claude 时用
`./scripts/install.sh --use-local-anthropic` 挂上 Anthropic 字体。

## 一、正文与中英混排

我写这段是为了看长段落的呼吸感。Claude 默认是 14px 正文字号、行高约 1.43（20/14）、栏宽 65ch。并排 Claude 窗口时，西文字形应接近 Anthropic Sans，中文走苹方。

比如这句里混着 `variable font`、opsz 轴、以及 300→800 的字重范围，看看西文和苹方交接得顺不顺。数字对齐也要看：2026 年、1,247 次、99.8% 的占比。

行内样式一次过：**加粗看字重是不是真的**、*斜体/软强调*、~~删除线~~、`行内代码`、[一个链接](https://example.com)、以及 ==高亮==。

### 三级标题：看字阶是否连贯

标题的负字距是高级感的主要来源，字号越大收得越多。h1 到 h4 应该形成清晰但不突兀的层级。

#### 四级标题

到这一级应该已经接近正文字号，靠字重和间距区分，而不是继续放大。

```python
def check(css):
    """判据必须能分辨合法与违规，一刀切等于没有区分力。"""
    problems = []
    for m in re.finditer(r"([^{}]+)\{([^{}]*)\}", css):
        selector = m.group(1).strip().split("\n")[-1].strip()
        if selector == "html":
            continue                      # 合法：根字号
        for fm in re.finditer(r"font-size:\s*[\d.]+px", m.group(2)):
            problems.append(f"{selector} 里 {fm.group(0)}")
    return problems
```
