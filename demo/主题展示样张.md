# hekouwang 主题展示样张

> 同一份内容，展示不同主题的色彩、标题、引用、代码与表格。

好的主题应让长文读得轻松，也让复杂信息一眼可辨。这里混排中文、English 与 `inline code`，用相同内容对比浅色和深色。宽屏时，正文有稳定的阅读列；表格与代码按内容需要获得空间。

## 一、从正文开始

阅读的节奏来自字重、行高与留白。`font-size: 16px`、数字 1,247 和链接应自然融入句子；**重要结论应清晰，但不刺眼**。

> 先让内容容易理解，再让页面拥有自己的气质。好的视觉语言，能帮助读者找到重点。

## 二、技术内容同样好读

下面的代码保持足够的对比度，长行在较窄窗口内由代码块自己滚动。

```python
def reading_width(viewport: int) -> str:
    return "48–96rem" if viewport >= 1440 else "fluid"
```

| 主题层级 | 阅读任务 | 设计重点 | 宽屏表现 |
| :--- | :--- | :--- | :--- |
| 标题 | 快速定位 | 对比与间距 | 与正文同列 |
| 正文 | 连续阅读 | 字形与行高 | 阅读列自适应 |
| 表格 | 横向比较 | 列宽与分隔 | 内容完整可见 |

同一份样张用于所有主题截图；实际界面以 Typora 中的主题 CSS 为准。
